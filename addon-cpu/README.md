# Wyoming RVC (CPU)

Give any text-to-speech voice an RVC timbre for Home Assistant Assist (Piper + RVC
over Wyoming), without CUDA or ROCm libraries. Recommended for official Home
Assistant OS on amd64; no GPU drivers or hardware access are required.

The voices and Wyoming integration match the GPU profiles, but CPU conversion is
noticeably slower. This is a separate installation with its own configuration and
model cache. See the Documentation tab for setup and migration notes.
